# robots.txt — angular-start-project
#
# Policy: the site is CLOSED by default (see the "User-agent: *" group at the bottom) and each
# crawler that is welcome is named here. Two kinds are welcome:
#
#   1. Search engines, so people can find the site.
#   2. AI assistants that READ the site to answer a question and cite it — the ChatGPT /
#      Claude / Perplexity search indexes, and the fetchers that run when a person pastes one
#      of our links into an assistant.
#
# What stays out is the third kind: crawlers that collect pages as MODEL TRAINING DATA. The
# content is here to be read and cited, not to be absorbed into a model's weights.
#
# Two caveats worth knowing:
#   - robots.txt is advisory. It is a published request, not an access control; anything that
#     must not be fetched needs a real authorization check on the server.
#   - The split only works where the vendor ships separate tokens for reading and training.
#     Where one token does both, it is denied.
#
# Group syntax: several "User-agent:" lines may share one set of rules (RFC 9309 §2.2.1), and a
# crawler obeys the most specific group matching its token — so a bot named below never falls
# through to "User-agent: *", whatever order the groups appear in.

# AI assistants — reading to answer, not to train. Full access.
#

# training crawler; the training half is denied in the next group. The "-User" tokens are not
# crawlers at all — they fire when a person asks the assistant to open one of our links, which
# is exactly the traffic this site wants.
# ---------------------------------------------------------------------------
